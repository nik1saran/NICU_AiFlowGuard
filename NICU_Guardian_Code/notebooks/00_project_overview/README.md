# 00 Project Overview

This section explains the business problem and product concept.

## Problem

NICU rounds and handoffs create many follow-up commitments. The work may be documented, but ownership and closure can become fragmented across notes, chats, task boards, and memory.

## Product concept

NICU Guardian adds a workflow reliability layer around Dragon Copilot:

1. Capture care-team conversation.
2. Extract commitments.
3. Score risk.
4. Route follow-up actions.
5. Track proof of closure.
